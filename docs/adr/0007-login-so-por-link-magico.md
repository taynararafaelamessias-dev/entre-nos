# Login só por link mágico

Ninguém cria senha: a pessoa entra pelo link enviado ao e-mail. Num app íntimo, isso tira o atrito
do cadastro e elimina senha fraca ou reutilizada. Em troca, o e-mail transacional vira dependência
crítica: sem e-mail entregue, ninguém entra.

O e-mail sai pelo Resend, nunca direto do servidor (cairia no spam). A política do Resend sobre o
segmento ainda não foi verificada; o texto do e-mail é neutro ("seu link para entrar").
