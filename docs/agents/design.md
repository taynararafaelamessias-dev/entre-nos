# Design (Doop)

Doop is the visual map of the product: every screen, flow and piece of visual structure is
prototyped on the Doop canvas first, and the native apps (Swift/Kotlin) are built from those
frames — layout, hierarchy, navigation and tokens.

- A new screen or a visual change starts on Doop.
- When code and canvas diverge, update the canvas, then the code.
- Tools: `mcp__doop__*`, starting with `get_guide({ topic: "doop-instructions" })`.
