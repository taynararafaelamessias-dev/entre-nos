# Entre Nós

App web para casais (PT/ES). Site estático em `site/` + Supabase.

- `site/` — o app (Cloudflare Pages: sem comando de build, pasta de saída `site`)
- `site/config.js` — URL e chave pública (anon) do Supabase
- `supabase/001_base.sql`, `supabase/002_jogos_comunidade.sql` — banco de dados (colar no SQL Editor, nessa ordem)
